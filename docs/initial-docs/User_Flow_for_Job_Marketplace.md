# User Flow for Job Marketplace [cite: 328]

## 1. Entry Points [cite: 329]
* From **Homepage Feature card** → **Explore Opportunities**. [cite: 330]
* From **Navigation bar** → **Features → Job Marketplace**. [cite: 331]

## 2. Landing Page (Job Marketplace Home) [cite: 332]
* **Hero text:** “Discover opportunities tailored for scientists.” [cite: 333]
* **Search bar:** Keyword / Role / Institution [cite: 334]
* **Filters:** Location, Research Area, Career Level, Job Type (Full-time/Part-time), Remote/On-site [cite: 335]
* **Job listings feed** (cards with Title, Institution, Location, Summary, Apply button). [cite: 336]

## 3. Exploration & Browsing [cite: 337]
**User can:** [cite: 338]
* Scroll through job listings. [cite: 339]
* Use **Search top bar** (e.g., “Molecular Biology Research Associate”). [cite: 340]
* Apply **Filters** to refine results (e.g. Location, salary, skills, remote, full time). [cite: 341]
* Adjusts **Sort by** (Relevance, Date posted, salary). [cite: 342]

## 4. Job Listings [cite: 343]
* When a job listing is clicked → Job details page opens: [cite: 344]
    * Job title, institution, requirements, deliverables. [cite: 345]
    * **Apply Now** button. [cite: 346]

## 5. Actions [cite: 347]

### Path A – Apply to a Job [cite: 348]
* **View Details** → opens full job description page. [cite: 349]
* **Apply Now**: Upload portfolio + cover letter in Authesci, or the necessary required details then submit. [cite: 350]
* **Confirmation message:** “Your application has been submitted.” [cite: 351]

### Path B – Save for Later [cite: 352]
* User clicks **Save Job** (if feature available). [cite: 353]
* Job is stored in **Saved Jobs** on their dashboard. [cite: 354]

### Path C – No Results [cite: 355]
* Search yields no results → System suggests: [cite: 356]
    * Adjusting filters. [cite: 357]
    * Related job categories. [cite: 358]
    * Sign up for **Job Alerts** (email notifications). [cite: 359]

## 6. Notifications / Alerts [cite: 360]
* Clicks **Alert Me** → sets up email/job notifications for similar roles. [cite: 361]
* Clicks **Save Search** → saves specific search queries for later reuse. [cite: 362]

## 7. Outcome [cite: 363]
* Application submitted (confirmation). [cite: 364]
* Job saved for tracking. [cite: 365]
* Alerts set for ongoing opportunities. [cite: 366]

## 8. Conversion / Value Delivery [cite: 367]
**Main outcomes:** [cite: 368]
* Applied to job(s). [cite: 369]
* Saved opportunities. [cite: 370]
* Signed up for job alerts. [cite: 371]
