# User Flow for Scientist’s Profile [cite: 202]

## 1. Entry Points [cite: 203]
* **For Scientist (Owner):**
    * After login → Dashboard → **My Profile** [cite: 204]
    * From navigation bar → Profile → Edit / Manage [cite: 204]
* **For Employer (Restricted View):**
    * Employer receives application → Click on applicant name → Scientist’s Profile view [cite: 205]

## 2. Scientist’s Profile (Owner View – Full Access) [cite: 206]
**Header Section:** [cite: 207]
* Profile Picture, Name, Role, Institution, Location [cite: 208]
* Verification badge [cite: 208]
* Import options: ORCID / Google Scholar [cite: 208]
* A progress bar (“Your profile is 80% complete”) [cite: 209]

**Tabs:** [cite: 210]
* **Overview** (Professional summary, skills, expertise, Job experience, profile stats) [cite: 210]
* **Publications** (imported from ORCID/Google Scholar) [cite: 210]
* **Past projects** [cite: 210]
* **AI Matches** (Suggests relevant job opportunities based on the scientist’s profile) [cite: 210]

**Actions (Owner):** [cite: 211]
* Edit Profile [cite: 211]
* Import Data [cite: 211]
* Analytics (profile views, application activity) [cite: 211]

**Profile Stats:** [cite: 212]
* **Publications** → total number of publications (pulled from ORCID/Google Scholar if linked, or manual input). [cite: 213, 214]
* **Projects** → number of research projects uploaded (covers students/postdocs without publications). [cite: 215]
* **Collaborations** → number of collaborators/institutions worked with. [cite: 216]
* **Skills** → number of skills/expertise tags listed. [cite: 217]

## 3. Employer View (Restricted – Only When Scientist Applies) [cite: 218]
**Employer sees a simplified profile after receiving an application:** [cite: 219]
* Scientist’s name, institution, and role [cite: 219]
* Professional summary (short bio) [cite: 219]
* Relevant skills & expertise [cite: 219]
* Publications (limited view or highlights) [cite: 219]
* Grants (if relevant to role) [cite: 219]

**Employer Actions:** [cite: 220]
* View applicant’s profile details [cite: 220]
* Shortlist / Save candidate [cite: 220]
* Contact candidate (messaging/email within platform) [cite: 220]

## 4. Outcomes [cite: 221]
* Scientist maintains full control of profile (private by default). [cite: 222]
* Employers can only view profiles **through applications**. [cite: 223]

# User Flow: Scientist Applying to a Job [cite: 224]

## 1. Entry Point [cite: 225]
* Scientist clicks **“Apply Now”** on a job listing (from Job Marketplace). [cite: 226]
* Or apply from the job recommendations in the scientist's profile. [cite: 227]

## 2. Application Page Opens [cite: 228]
**Displays the Job Summary at the top for context:** [cite: 229]
* Job Title [cite: 230]
* Institution / Organization [cite: 231]
* Location (Remote/On-site) [cite: 232]
* Salary [cite: 233]
* Application Deadline [cite: 234]

## 3. Application Form (Fields to be Displayed) [cite: 235]
**Scientist fills in the following:** [cite: 236]

### A. Basic Details (auto-filled from profile where possible) [cite: 237]
* Full Name [cite: 238]
* Email Address [cite: 239]
* Institution / Affiliation [cite: 240]
* Role / Position [cite: 241]

### B. Supporting Documents [cite: 242]
* **CV / Resume** (upload or use saved CV in Authesci profile) [cite: 243]
* **Cover Letter** (text box or upload PDF) [cite: 244]
* **Portfolio / Project Links** (optional) [cite: 245]

### C. Additional Information [cite: 246]
* Research Area / Specialization (dropdown or auto-filled from profile) [cite: 247]
* Skills relevant to the job (checkbox from profile skills) [cite: 248]
* Availability (Immediate / Within 1 month / Flexible) [cite: 249]
* Location Preference (Remote / On-site / Hybrid) [cite: 250]

### D. Compliance / Agreement [cite: 251]
* Checkbox: “I confirm that the information provided is accurate.” [cite: 252]
* Checkbox: “I agree to share my profile with the employer for this application.” [cite: 253]

## 4. Review & Submit [cite: 254]
* Scientist reviews application summary (auto-generated preview). [cite: 255]
* Click **“Submit Application”**. [cite: 256]

## 5. Confirmation & Tracking [cite: 257]
* Success message: “Your application has been submitted.” And also receives an email. [cite: 258]
* Application is stored in **Dashboard → My Applications** with status: [cite: 259]
    * Submitted / Under Review / Shortlisted / Rejected / Hired. [cite: 260]
* Option to **withdraw application** (before deadline). [cite: 261]

## Employer View (Fields Visible to Employer) [cite: 262]
**When an employer reviews an application, they see:** [cite: 263]
* Scientist’s **Profile Overview** (summary, skills, profile stats). [cite: 264]
* CV / Resume. [cite: 265]
* Cover Letter. [cite: 266]
* Relevant Publications / Projects (linked to profile). [cite: 267]
* Portfolio links (if provided). [cite: 268]
