# User Flow: In-Lab Mode (Physical Collaboration) [cite: 88]

## 1. Entry Point [cite: 89]
* Scientist logs in → navigates to **In-Lab Mode tab**. [cite: 90]
* Sees available labs offering physical collaboration slots. [cite: 91]

## 2. View Lab Details [cite: 93]
**Scientist clicks on a lab card → sees:** [cite: 94]
* Lab Name & Institution [cite: 95]
* Research Area / Facilities available [cite: 96]
* Available Dates or Time Slots [cite: 97]
* Requirements (e.g., must be MSc/PhD, safety training, etc.) [cite: 98]
* Contact Person [cite: 99]

## 3. Request Access [cite: 100]
* Scientist clicks **“Request to Join Lab”**. [cite: 101]
* **Simple form:** [cite: 102]
    * Full Name (auto-filled from profile) [cite: 103]
    * Institution [cite: 104]
    * Role (Student, Researcher, etc.) [cite: 105]
    * Reason for Request (short text) [cite: 106]
* **Submit.** [cite: 107]

## 4. Outcome [cite: 108]
* Lab owner receives notification → can **Accept / Decline**. [cite: 109]
* If accepted → Scientist gets confirmation & lab access details. [cite: 110]

# User Flow: Virtual Mode (Collaboration / Discussion) [cite: 111]

## 1. Entry Point [cite: 112]
* Scientist logs in → navigates to **Virtual Mode tab**. [cite: 113]

## 2. Join a Virtual Session [cite: 114]
* Scientist sees upcoming **virtual collaboration rooms** or **discussion sessions**. [cite: 115]
* **Each card shows:** [cite: 116]
    * Topic / Research Focus [cite: 117]
    * Host Lab or Scientist [cite: 118]
    * Date & Time [cite: 119]
    * Mode (Zoom, Google Meet, or Authesci room MVP → simple chat/video link) [cite: 120]

## 3. Request to Join Session [cite: 121]
* Scientist clicks **“Join Session”**. [cite: 122]
* **Options:** [cite: 123]
    * If **Open Session** → direct entry (join link). [cite: 124]
    * If **Restricted Session** → must request access (short form: Name, Role, Institution). [cite: 125]

## 4. Collaboration Space [cite: 126]
**MVP Feature:** [cite: 127]
* Redirect to Zoom/Meet (external link) OR [cite: 128]
* Simple embedded chat/video window inside Authesci. [cite: 129]

## 5. Outcome [cite: 130]
* Scientist participates in session. [cite: 131]
* Option to connect with host/collaborators afterward. [cite: 132]
