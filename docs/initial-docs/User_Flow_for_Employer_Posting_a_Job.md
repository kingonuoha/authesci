# User Flow for Employer Posting a Job [cite: 1]

## 1. Entry Point
**Employer logs in** → Employer Dashboard. [cite: 3]
Clicks **“+ Post New Job”** button. [cite: 4]

## 2. Job Posting Form (Fields to be Filled) [cite: 5]

### A. Basic Job Info [cite: 6]
**Job Title** [cite: 7]
**Institution / Organization** [cite: 8]
**Location** (City, Country, Remote option) [cite: 9]
**Job Type** (Full-time / Part-time / Contract / Internship) [cite: 10]

### B. Job Description [cite: 11]
**Overview / Summary** (short pitch about the role) [cite: 12]
**Responsibilities** (bullet points) [cite: 13]
**Requirements** (qualifications, skills) [cite: 14]

### C. Additional Details [cite: 15]
**Salary Range** (negotiable checkbox) [cite: 16]
**Research Area / Discipline** (dropdown: Biology, AI in Health, Genomics, etc.) [cite: 17]
**Funding Source** (optional – if grant funded) [cite: 18]

### D. Application Settings [cite: 19]
**How candidates apply:** [cite: 20]
    Type out the Cover Letter (default) [cite: 21]
    Upload resume [cite: 22]
    Upload portfolio (optional) [cite: 23]

### E. Confirmation [cite: 24]
Employer reviews job details → Clicks **“Publish Job”**. [cite: 25]

## 3. Success State [cite: 26]
Job posting goes live on Job Marketplace. [cite: 27]
Employer sees confirmation message: “Your job has been posted successfully.” [cite: 28]
Job appears under **Dashboard → Job Postings** with status **Active**. [cite: 29]

## Employer Dashboard User Flow [cite: 30]

### 1. Overview (Dashboard Home) [cite: 32]
**Quick stats:** [cite: 33]
Total Active Jobs [cite: 34]
Total Applicants [cite: 35]
Pending Applications [cite: 36]

### 2. Job Postings Tab [cite: 37]
**List of all jobs posted with key details:** [cite: 38]
Job Title [cite: 39]
Location & Type [cite: 40]
Status (Active / Closed) [cite: 41]
Applicants count [cite: 42]
Date Posted [cite: 43]
**Actions:** Edit, Close Job, View Applications [cite: 44]

### 3. Applications Tab [cite: 45]
Shows candidate applications per job. [cite: 46]
**Filters:** By Job Title, Status (Submitted, Shortlisted, Hired). [cite: 47]
**For each candidate:** [cite: 48]
    Name & Institution [cite: 49]
    CV & Cover Letter [cite: 50]
    Skills & Profile Stats (pulled from Authesci profile) [cite: 51]
    **Actions:** Shortlist, Reject, Contact Candidate [cite: 52]

### 4. Post Job Tab [cite: 53]
Shortcut to new job posting form (same as described above). [cite: 54]

### 5. Notifications / Alerts [cite: 55]
**Alerts for:** [cite: 56]
Applications from scientist. [cite: 57]
Jobs about to expire. [cite: 58]

## Employer Outcomes [cite: 59]
Successfully posts & manages jobs. [cite: 60]
Tracks applications in one place. [cite: 61]
Shortlists, contacts, or rejects candidates efficiently. [cite: 62]
Dashboard provides a central hub for hiring workflow. [cite: 63]
