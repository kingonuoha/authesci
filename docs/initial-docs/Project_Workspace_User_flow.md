# Authesci Project Workspace – MVP User Flow [cite: 64]

## 1. Entry Points [cite: 65]
**For Scientist (Owner):** [cite: 66]
    Login → Dashboard → Select Project → Project Workspace [cite: 67]
    Sidebar → Projects → Click on Project Card [cite: 68]
**For Collaborator / Employer (Restricted Access):** [cite: 69]
    Invitation via project link → Access shared workspace [cite: 70]

## 2. Project Workspace Structure [cite: 71]
**Sidebar Navigation (persistent):** [cite: 72]
Dashboard [cite: 73]
Projects [cite: 74]
Documents [cite: 75]
Tasks [cite: 76]

## 3. Dashboard (Workspace Overview) [cite: 77]
**Header:** “Welcome back! Here’s what’s happening with your projects.” [cite: 78]
**Feature Cards:** [cite: 79]
    **Active Projects:** Show project title, number of members, due date, progress bar, and upcoming deadlines. [cite: 80]
    **Tasks in Progress / Completed Tasks:** Snapshot of task status. [cite: 81]
    **Shared Documents:** Quick access to recently shared files. [cite: 82]
**Quick Action Card:** “Start something new” → options: Create Project, Add Task, Upload Document. [cite: 83]
**Recent Activity Feed:** Logs of actions (new task, file upload, comment, deadline updates). [cite: 84]

## 4. Projects Tab [cite: 85]
**Text:** “Manage your research projects and team collaboration.” [cite: 86]
**Project Cards:** [cite: 87]
    Title + Status (Active / Completed) [cite: 88]
    Tasks (count), Members (count), Documents (count) [cite: 89]
    Due date and progress bar [cite: 90]
**Actions:** [cite: 91]
    View all projects in a grid/list [cite: 92]
